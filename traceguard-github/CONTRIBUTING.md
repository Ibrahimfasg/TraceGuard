# Contributing

Keep changes small and easy to review.

When you add or change a rule:

1. Add one example that should be reported.
2. Add one safe example that should not be reported.
3. Explain the rule in the rule reference.
4. Run `npm test`, `npm run typecheck`, and `npm run build`.

Use invented values in test examples. Do not commit real passwords, tokens, or keys.

TraceGuard is an educational scanner. Be clear about what a rule can and cannot detect.
